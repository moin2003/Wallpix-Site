# SEO and Content Guidelines

Follow these guidelines whenever writing content, creating wallpaper collections, or optimizing metadata:

1. **Title and Meta Guidelines**:
   - Page Titles: 50–60 characters. Format: `{Primary Keyword} - {Benefit/Resolution} | {Site Name}`
   - Meta Descriptions: 140–155 characters. Include clear call to action and secondary keywords.
   - Clean URL Slugs: All lowercase, hyphen-separated, free of special characters (e.g., `/dark-nature-wallpapers-4k`).

2. **Image SEO**:
   - File names must be descriptive (e.g., `minimalist-mountain-sunset-4k.webp`, NOT `IMG_3021.webp`).
   - Image `alt` text must be descriptive and context-rich without keyword stuffing.

3. **Structured Data**:
   - Inject schema markup on every page: `Article` for blogs, `ImageObject` or `CollectionPage` for galleries, and `BreadcrumbList` for navigation hierarchy.

4. **Internal Linking**:
   - Every collection page must link to at least 3-5 related categories or tags to distribute link equity and increase user engagement time.
